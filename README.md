# Emulator List By Jaloliddin

A comprehensive database of emulators for all systems from 1960s-2026. This repository contains detailed information about active, discontinued, and abandoned emulators across all major platforms.

## 📦 Repository Structure

- **`active.json`** - 500+ active emulators organized by system
- **`discontinued.json`** - 400+ discontinued/abandoned emulators with historical data
- **Related Repositories:**
  - `emulator-listByJaloliddin-android` - Android-specific emulators
  - `emulator-listByJaloliddin-windows` - Windows-specific emulators

## 📊 Data Format

Each emulator entry includes:
```json
{
  "name": "Emulator Name",
  "github": "https://github.com/...",
  "status": "active/discontinued/abandoned",
  "platforms": ["Windows", "Linux", "macOS"],
  "year_released": 2020,
  "systems": ["System Name"],
  "description": "Optional description"
}
```
